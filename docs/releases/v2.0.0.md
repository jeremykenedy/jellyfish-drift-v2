# Jellyfish Drift V2 2.0.0

This first release is a separate filmed app, installed beside classic Jellyfish Drift. It uses a new package and unique signer rather than replacing the classic scene.

## Upgrade guide

This is a new installation, not an in-place upgrade of classic Jellyfish Drift. Android 6.0/API 23 is the minimum. Install the published APK or run `python3 install.py --serial TV_IP:5555` once the verified release is available. Installation does not change the selected Dream or system timers. Choose Jellyfish Drift V2 separately when ready; the original app and its saved settings remain installed.

No account, runtime content download, database migration, environment change, cache clear, or service restart is required. Uninstalling V2 removes only V2 data. Selecting classic Jellyfish Drift is the reversible way to return to the original scene.

## Breaking changes

There are no prior releases of this package. It does not import the original app's preferences. Only scene, playback speed, optional clock, and randomization are supported; recorded animal density, species, and lighting are fixed by each recording.

## Major changes

Blue aquarium and Deep ocean are silent licensed recordings with 1080p H264 and a 720p fallback. Preview and Dream share the offline player lifecycle. Native settings include full source notices and licenses outside the screensaver scene. Show clock is off by default and slowly drifts when enabled. Its saved on/off choice is independent of scene randomization.

## Minor changes and fixes

The new provider acknowledges successful preference commits. Installer downloads require published checksums. No runtime framework dependency, analytics, tracking, or network permission is added.

## Verification and limits

The current 2.0.0/code 2 candidate passes local settings/installer tests, formatter, full pure-Java coverage, native same-signer legacy retention, 4-row schema, D-pad clock on/off, randomization independence, visible 20-second clock drift, Settings/Credits/Close, Preview, and Back. Physical API 30 normal Dreams passed two paired presets: Blue aquarium 0.9x clock off at a minimum sampled 27.00 FPS and Deep ocean 1.25x clock on at 36.59 FPS. Sampling used actual SurfaceFlinger presentation timestamps after settling, without screen recording; separate windows do not establish continuous full-duration pacing. Native controls and strict surrounding-state restoration passed. The full GitHub light/still banner media-selection matrix remains unverified. Release artifacts use this app's unique signer and published SHA-256 sidecar. Native 4K, sustained thermal behavior, physical Google TV, and owner visual acceptance are not claimed.
